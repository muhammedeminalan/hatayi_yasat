# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

Changes since the last store release are tracked in the commit history and are summarized
here when a release is tagged.

## [8.2.0] – [8.3.x]

These builds shipped to the App Store and Google Play without individual changelog entries.
See the [commit history](https://github.com/VB-CORE/hatayi_yasat/commits/main) for what
changed. The `version:` field in `pubspec.yaml` is the source of truth for the current build.

Notable work in this range: community groups and discussions, place ratings, the merchant
panel, campaigns and QR coupon redemption, Google / Apple sign-in with guest mode, and the
migration to the `FirestoreResult` / `StorageResult` service API from `life_shared`.
